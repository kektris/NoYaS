# NoYaS
NoYaS is a project of de-Yandexing YaStations. Currently, this project is still in testing, but you can build it

# Build
## Requirements
- any Yandex Station (except Duo Max/Street/Xiaomi Smart Display/any TV Station)
- WiFi and Bluetooth-compatible SBC (ex. Raspberry Pi Zero 2W)
- Installed any Debian distribution
### Not necessary additional features
- Spotify desktop app (for linking Spotify)
- Chromium (for search features)
