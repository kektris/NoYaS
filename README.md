# NoYaS
NoYaS is a project of de-Yandexing YaStations. Currently, this project is still in testing, but you can build it

# Build
## Requirements
- any Yandex Station (except Duo Max/Xiaomi Smart Display/any TV Station)
- WiFi and Bluetooth-compatible SBC (ex. Raspberry Pi Zero 2W) *(but any pc on debian should work fine)*
- Installed any Debian distribution (i recommend using Armbian)
### Not necessary additional features
- Spotify desktop app (for linking Spotify)
- Home Assistant (for bridge between Yandex and HAOS)
- Chromium Browser (for search features)
